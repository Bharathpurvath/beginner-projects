# Beginner Projects

Open `index.html` to launch any project. Projects 1–16 are listed on the homepage. Projects 6–16 are in their own folders. Browser-based project data is saved locally in your browser. Weather, Movie Search, and GitHub Profile Finder need internet access.

Project 16, Learning Garden, is available at [`learning-garden/`](learning-garden/). Its public edition saves each visitor's courses and lesson progress in that browser's local storage; it does not use the local FastAPI sign-in backend or sync data between devices.


## Intermediate Projects

Explore all 16 full-stack projects in the [Intermediate Projects gallery](intermediate-projects/index.html). Each project includes its source code and setup README. The Python API backends must be run separately; GitHub Pages hosts the gallery and source files, not the backend services. Learning Management System also has a [browser-only demo](learning-garden/index.html).
